## Common Sets

| Symbol       | Name                        | Definition                                                      | Example                      |
| ------------ | --------------------------- | --------------------------------------------------------------- | ---------------------------- |
| $\mathbb{N}$ | Set of all Natural numbers  | $\{1, 2, 3, \dots\}$ (counting numbers)                         | $5 \in \mathbb{N}$           |
| $\mathbb{Z}$ | Set of all Integers         | $\{\dots, -2, -1, 0, 1, 2, \dots\}$                             | $-3 \in \mathbb{Z}$          |
| $\mathbb{Q}$ | Set of all Rational numbers | $\left\{ \frac{a}{b} : a, b \in \mathbb{Z},\ b \neq 0 \right\}$ | $\frac{2}{3} \in \mathbb{Q}$ |
| $\mathbb{R}$ | Set of all Real numbers     | All points on the number line (rationals + irrationals)         | $\sqrt{2} \in \mathbb{R}$    |

## Quantifiers

| Symbol    | Name                   | Meaning                                                             | Example                                 |
| --------- | ---------------------- | ------------------------------------------------------------------- | --------------------------------------- |
| $\forall$ | Universal quantifier   | "for all" / "for every" — the statement holds for **every** element | $\forall x \in \mathbb{R},\ x^2 \geq 0$ |
| $\exists$ | Existential quantifier | "there exists" — the statement holds for **at least one** element   | $\exists x \in \mathbb{Z},\ x^2 = x$    |
